YouTube OAuth 앱 전용 조항

1. 앱의 목적과 운영 범위

thelc-youtube-desktop은 YouTube Data API v3와 Google OAuth 2.0을 사용하는 데스크톱 자동화 도구입니다. 승인한 사용자의 YouTube 채널을 확인하고, 사용자가 지정한 동영상과 메타데이터를 업로드하며, 업로드 결과·처리 상태·재생목록 반영 여부를 확인하는 용도로만 사용합니다.

Google Cloud의 현재 설정상 사용자 유형은 외부, 게시 상태는 테스트 중이며, 등록된 테스트 사용자만 앱에 접근할 수 있습니다. 별도의 공개 회원가입 기능은 없습니다.

2. 요청하는 Google OAuth 권한

OAuth 범위 사용 목적
https://www.googleapis.com/auth/youtube.readonly 승인한 YouTube 채널과 동영상·재생목록 정보 및 처리 상태를 조회하고 작업 결과를 검증합니다.
https://www.googleapis.com/auth/youtube.upload 사용자가 지정한 동영상을 승인한 YouTube 채널에 업로드합니다.
https://www.googleapis.com/auth/youtube 승인한 채널의 동영상 제목·설명·미리보기 이미지·공개 상태 등 메타데이터와 재생목록 항목을 관리합니다.

앱은 위 권한을 통해 Google 계정 비밀번호를 요청하거나 수집하지 않습니다. 인증과 동의는 Google의 OAuth 화면에서 처리됩니다.

3. 접근·수집·저장하는 정보

  • OAuth 액세스 토큰, 갱신 토큰 및 승인된 권한 범위
  • 승인한 YouTube 채널의 채널 ID, 채널명, 맞춤 URL 및 업로드 재생목록 식별자
  • YouTube API가 반환하는 동영상 ID, 제목, 설명, 미리보기 이미지, 공개·처리 상태, 게시 시각 및 재생목록 식별자
  • 사용자가 자동화 실행을 위해 지정한 동영상, 미리보기 이미지, 제목, 설명, 태그 및 공개 설정

OAuth 토큰은 운영자가 관리하는 로컬 자동화 환경에 저장됩니다. YouTube 동영상 식별자와 메타데이터, API 작업 결과는 업로드 검증과 관련 서비스 표시·관리를 위해 로컬 작업 기록 및 관련 서비스 데이터베이스에 저장될 수 있습니다.

4. 정보 이용, 공유 및 처리위탁

위 정보는 사용자가 승인한 YouTube 자동화 기능을 제공하고 오류를 확인하는 데만 이용합니다. Google 사용자 데이터를 판매하거나, 맞춤형 광고·리타게팅·감시·신용평가 목적으로 이용하거나, 데이터 브로커 또는 광고 플랫폼에 제공하지 않습니다.

  • Google LLC / YouTube: OAuth 인증과 YouTube Data API 요청 처리
  • Supabase Inc.: 관련 서비스의 PostgreSQL 데이터베이스 운영. YouTube 동영상 식별자와 메타데이터가 관련 서비스 표시·관리를 위해 저장될 수 있으며, OAuth 토큰은 이 데이터베이스에 저장하지 않습니다.

그 밖에는 사용자의 별도 동의가 있거나 법령상 의무를 이행해야 하는 경우를 제외하고 Google 사용자 데이터를 제3자에게 제공하지 않습니다.

데스크톱 앱은 광고를 제공하거나 맞춤형 광고를 위한 추적 기술을 사용하지 않습니다. 이 개인정보 처리방침 페이지도 입력 양식, 광고 또는 분석·추적 스크립트를 포함하지 않습니다.

5. 보유 기간과 삭제

  • OAuth 토큰은 사용자가 접근 권한을 유지하고 자동화 기능을 사용하는 동안 보유합니다.
  • YouTube API 작업 결과와 승인된 데이터는 업로드 검증 및 관련 콘텐츠 관리에 필요한 동안 보유합니다.
  • 사용자가 권한을 철회하거나 삭제를 요청하면 해당 OAuth 토큰과 그 동의에 근거해 저장한 승인 데이터를 가능한 한 즉시, 늦어도 7일 이내에 삭제합니다. 법령상 보존 의무가 있는 정보는 해당 의무 기간에만 별도로 보관합니다.
  • 로컬 또는 관련 서비스에서 데이터를 삭제하거나 OAuth 권한을 철회해도 이미 YouTube에 게시된 콘텐츠는 자동 삭제되지 않습니다. 해당 콘텐츠는 사용자가 YouTube 또는 YouTube Studio에서 별도로 관리할 수 있습니다.

7. 보안 조치

OAuth 토큰 파일은 운영자 계정만 접근할 수 있도록 제한하고, 토큰·클라이언트 보안 비밀·인증 코드를 공개 저장소나 공개 로그에 기록하지 않습니다. Google API 통신에는 HTTPS를 사용하며, 접근 권한은 자동화 운영에 필요한 담당자로 제한합니다.
